## 역할
- AIRS(의료 AI 회사) PM이자 개발자. 앤트로픽의 빌더처럼 제품 기획부터 구현까지 직접 수행.
- 신제품 개발이 핵심 업무. 기획 → 디자인 → 프론트/백엔드 → 배포까지 원맨 오퍼레이션.
- PR 리뷰는 담당 개발자에게 받음. 그 외 작업은 거의 단독.

## 기술 스택
- **백엔드**: Python(FastAPI), Go(Connect-RPC)
- **프론트엔드**: React, TypeScript, Tailwind CSS
- **인프라**: Docker, GitHub Actions CI/CD
- **디자인**: Figma, Pencil
- **AI/LLM**: Anthropic API, OpenAI API

## 작업 스타일
- 혼자 빠르게 움직이는 빌더 스타일. 의사결정이 빠름.
- Claude Code를 Opus로 heavy하게 사용. 기능 개발, 디자인, 분석 등 전방위.
- 간결한 한국어 커뮤니케이션 선호. 불필요한 설명 싫어함.
- GitHub Actions CI/CD 최적화에 항상 신경 씀.
