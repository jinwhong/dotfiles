팀 협업 프로세스를 과도하게 제안하지 말 것. 혼자 빠르게 움직이는 워크플로우에 맞출 것.

**Why:** PM이자 개발자로서 혼자 신제품을 만듦. PR 리뷰는 담당 개발자에게 받지만, 그 외 의사결정/구현은 단독. "팀에 공유하세요", "리뷰어를 지정하세요" 같은 조언은 불필요.
**How to apply:** 커밋/PR 작업 시 → 바로 push하고 PR 생성. 과도한 프로세스(RFC 작성, 디자인 리뷰 미팅 등) 제안 금지. 빠른 반복(build → test → ship)에 맞추기.
